Nhập môn GraphQL

Schema · Query · Resolver · DataLoader · Cache — client tự gọi món, server dọn đúng đĩa

REST là thực đơn set sẵn: mỗi endpoint dọn một mâm cố định, thừa món này thiếu món kia. GraphQL là gọi món: client viết ra đúng những field mình cần, server trả về đúng hình dạng đó. Mỗi bài gồm 4 phần: lý thuyết ngắn → code demo có tab → animation từng bước (bấm để xem query chạy qua schema, resolver, database) → trắc nghiệm.
