Nhập môn Kotlin Multiplatform (KMP)

Chia sẻ logic Android/iOS, giữ UI native

Khoá dành cho dev Java/RN muốn hiểu KMP từ gốc: project Gradle, expect/actual, Kotlin/Native và cách Swift gọi Kotlin, thư viện đa nền tảng, kiến trúc chia sẻ, phân phối cho iOS, bộ nhớ và lộ trình rời React Native. Mỗi bài gồm 4 phần: lý thuyết → code demo có tab → animation từng bước → trắc nghiệm.
